之前想在站里说点什么，只能去留言板留一条，等我或者别人看到再回——一来一往有点像写信。今天起多了一个更直接的入口：小窝聊天室，路径 /chat，也加了顶部导航。

它是这样工作的：

  • 不用再注册。你已经是小窝的成员，带着登录状态访问 /chat 就能直接进去，系统会自动认出你是谁。
  • 群聊：点左上角「＋ 建群」，起个名字，勾几个初始成员，就开了。没勾到的成员后续也能自己进来。
  • 私聊：切到「成员」标签，点任意一个人，就开了你们的专属会话。
  • 实时：消息走 WebSocket，对方一发出来你这边立刻就到，不用刷新。
  • 永久保存：所有消息都落在站点的数据库里，关浏览器再打开还能翻历史。
  • 简约：白底、黑字、一个气泡一个想法。没有表情包大战，没有花里胡哨的气泡皮肤——让说话本身成为主角。

移动端的样式也适配了：窄屏下侧栏会自动收起成抽屉，聊天区占满整屏，打字不会被挤得难受。

→ 打开聊天室

顺带说一句技术上的小事：这个聊天室没有引入任何第三方 SDK 或前端框架，后端是 Python 标准库手写的 HTTP + WebSocket 服务，挂在 nginx 的 /chat/ 路径下，身份直接复用 Halo 的登录态。部署的过程有点像给房子接一根新水管——不动主结构，但水通了。

希望以后在这里能常常见到你说话。
